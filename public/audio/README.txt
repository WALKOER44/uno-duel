# Audio: Good Life (BGM)

Letakkan file MP3 **milikmu sendiri** di folder ini dengan nama:

    good-life.mp3

Ini adalah lagu "Good Life" (G-Eazy feat. Kehlani) yang sudah kamu miliki secara legal
(file MP3 rekaman/lisensi pribadi). File tidak dibundel ke repo karena hak cipta.

Jika file tidak ada, game otomatis memakai musik latar sintesis (Web Audio) sebagai pengganti.
Volume musik diatur lewat menu Pengaturan (⚙️) di dalam game.

Format yang didukung: MP3 / OGG / WAV (nama file harus tetap `good-life.mp3`).
